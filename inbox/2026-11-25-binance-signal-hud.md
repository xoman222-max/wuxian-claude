## 一句話摘要
Gemini 幫使用者做了一個疊在幣安合約頁上的「訊號儀表板」（Chrome MV3 擴充 → 手機 HTML → Android 懸浮窗 APK，v1.0～v1.5），用幣安公開 API 算 MA7/25/99、RSI、量比、溢價、資金費率、OI，再加上多週期判斷、前高前低和風控計算機。可以重複用的是架構和訊號規則；行情敘事不可信。

## 核心內容

### 1. 架構（不碰 canvas）
- 幣安 K 線畫在 `<canvas>`，直接改容易隨改版失效 → 改成**浮動 DOM 面板**，自己抓資料自己算。
- 交易對從網址解析：`/futures/([A-Z0-9]+)/`。
- 公開端點（不用 API key）：
  - `GET https://fapi.binance.com/fapi/v1/klines?symbol=X&interval=15m&limit=120`（k[1]開 k[2]高 k[3]低 k[4]收 k[5]量）
  - `GET /fapi/v1/premiumIndex?symbol=X`（markPrice、indexPrice、lastFundingRate）
  - `GET /fapi/v1/openInterest?symbol=X`（張數，乘價格得名目 OI）
- 每 8 秒刷新；懸停解說用**事件委派**（`hud.addEventListener('mouseover', e.target.closest('[data-tip]'))`），重繪 innerHTML 時 tooltip 才不會閃掉。
- 版本演進：v1.1 懸停解說 → v1.2 三週期同框＋BTC 對照＋風控計算機（localStorage 記本金/風險%）→ v1.3 Pivot 前高/前低＋區間位置條 → v1.4 拆股斷層濾除＋1m → v1.5 印出 MA 數值、自動跟幣安週期按鈕連動、Wilder RSI。對話裡只有 v1.0／v1.1 的完整原始碼，v1.2 以後都是 Gemini 產生的 ZIP，沒有存下來。

### 2. 訊號規則（v1.1 參數）
| 訊號 | 條件 |
|---|---|
| MA7 金叉/死叉 MA25 | 前一根 MA7≤MA25 且這根 MA7>MA25（反之為死叉） |
| 跌破/站上 MA99 | 前一根收盤在 MA99 一側，這根收在另一側 |
| 創高縮量（假突破） | 最高價 ≥ 前 19 根最高價，且量比 < 0.85 |
| 爆量插針 | 量比 > 1.6，且下影線 > 實體 × 1.5 |
| RSI 極值 | RSI(14) ≥ 72 為超買；≤ 28 為超賣 |
| 溢價警示 | 偏離超過 0.15% |
| 拆股斷層（v1.4） | 相鄰 K 線差距超過 2.8 倍時，捨棄斷層前的資料；不足 99 根就用全部有效根數，標成 MA96* |
量比 = 當根量 ÷ 前 20 根均量。

### 3. 交易框架（對話中反覆用到的方法論）
- 多週期分工：「4h 定方向，1h 找位置，15m 確認結構，5m/1m 決定進場」，逆大週期的訊號只能當反彈看。
- 在 MA99 下方不猜底：第一波反彈先當逃命波。要等二次探底站穩（W 底），或放量站回 MA99 再回踩不破。
- 「區間位置條」：價格在前低和前高之間落在 40～75% 時不動手，只在 25% 以下或突破後回踩時考慮。
- 風控三條：止損放在結構失效點；單筆虧損 ≤ 本金 1～2%；盈虧比 R:R ≥ 1.5。到第一目標先平 50～70%，剩下的移到保本止損。
- 美股掛鉤合約的時間點（台灣時間、冬令）：17:00 盤前開始；20:00 美國主流券商盤前開放；21:30 公布經濟數據；22:30 正規開盤，開盤後 15 分鐘最亂；23:30（美東 10:30）才是當天真正的方向分水嶺。
- 只看四種單根 K 線：長下影、長上影、十字星、光頭光腳。組合形態只看四種：吞沒、孕線、雙針、晨星/黃昏星。K 線一定要等收盤才算數。

## 可重複使用的規則或模板（含拆解時抓到的坑）
1. **用到還沒收完的 K 線（v1.1 的 bug）**：最後一根還在形成，量比天生偏低，所以「創高縮量」在每根開頭幾乎都會誤報，插針判斷也一樣。修法：訊號改用 `klines[len-2]`（已收盤的那根），或把當根量除以已經過的時間比例再比較。
2. RSI 原本是簡單加總，跟幣安/TradingView 對不上，要改成 Wilder 平滑（v1.5 已改）。
3. MA99 穿越原本拿上一根收盤比「這根的 MA99」，價格貼線時會反覆誤報，要比 prevMa99（v1.5 已改）。
4. 程式碼裡的 `spreadPct` 是拿最新價對 **markPrice**，但面板說明寫的是「對現貨指數」，應該改用 `premium.indexPrice`。
5. 有效 K 線不到 99 根時（新上市或拆股後），`calcMA` 會回傳 null，`ma99.toFixed` 就會出錯；v1.1 遇到時直接 return，面板會一直卡在「載入中」。
6. 面板沒印出 MA 數值時，使用者沒辦法和圖表對帳。所以第一版就要印出數值，並且跟網頁上選的週期連動。
7. 寫進面板的資料都要先跳脫再放進 innerHTML；這裡因為交易對經過 `[A-Z0-9]` 過濾，風險才低。
