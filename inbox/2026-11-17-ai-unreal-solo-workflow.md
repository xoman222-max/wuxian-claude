## 一句話摘要

一個人十天用 Tripo 建模、Claude 搭場景和特效、Codex 做動作和戰鬥邏輯，在 Unreal 裡做出古寺 Boss 戰 demo；作者的結論是個人用 AI 做到 3A 級目前不可能。

## 核心內容

### 分工
- Tripo：人物、武器、建築、場景物件建模，也能綁骨骼（或用 AccuRIG）。
- Claude：依參考圖搭白模、替換模型、調燈光曝光、用 Niagara 做水墨、劍氣、火花特效。作者認為 Claude 的三維空間理解比 Codex 少幾輪迭代。
- Codex：生地圖概念圖和全寺佈局、導入角色、配跑跳、Chaos Cloth 衣擺、動作重映射、連招與格擋受擊過渡。

### 流程
1. 場景：Codex 生山門主視覺 → 補全寺佈局和各位置視角 → Claude 用簡單幾何體搭白模 → 人眼對照參考圖 → Claude 呼叫 Tripo 批量生成模型並按白模位置替換 → 對照參考圖調燈光。
2. 角色：人物和武器在 Tripo 單獨做（自己把控）→ 綁骨骼 → 動作預覽檢查抬手、彎腿有無拉伸 → Codex 導入 UE 配基礎動作。
3. 戰鬥：從 Mixamo 和 Fab 選動作素材，用白色機器人並排演示來挑招式 → Codex 重映射到自製角色（骨架和比例不同要重新對應）→ Claude 做特效 → 實際對戰，把停頓和生硬的畫面加修改要求丟回 Codex。

## 可重複使用的規則或模板

批量生成場景資產時，提示詞統一加：`單個獨立物體，完整展示，寫實，比例準確`。

山門概念圖提示詞（原文）：

```
深秋山谷里，一座荒废多年的中国古寺。镜头放低到荒草的高度，从院外斜望山门。左前景是一尊被风雨磨钝的石狮，旁边立着一块顶部残缺的旧石碑。几级错位的青石台阶，从画面下方延伸到中景的双层木构门楼。门楼仍保留完整的轮廓，灰瓦屋面局部塌陷，檐口微微起翘，暗红木柱褪色露出木纹，土黄色墙皮成片剥落。枯草从石阶接缝和墙根长出，地上散落着碎瓦和褐色落叶。光秃的树枝从画面两侧伸入，右后方的古塔在山雾中只剩淡淡的轮廓。低角度的侧逆光掠过庭院，只照亮草尖、石碑的一侧和几道瓦脊，门洞与檐下保留深而通透的阴影。近景是低饱和的枯草金、灰褐石材和旧木色，远景逐层过渡到淡蓝灰。焦点落在中景门楼，最靠近镜头的草叶轻微虚化。写实古代游戏环境截图，自然曝光，石材粗糙、干燥、有细小崩口，安静无人。
```

提示詞結構可套用：地點與時節 → 機位高度與方向 → 前景物 → 中景主體（輪廓、材質、破損）→ 遠景 → 光線方向與明暗 → 色彩分層 → 焦點 → 風格與材質收尾。
