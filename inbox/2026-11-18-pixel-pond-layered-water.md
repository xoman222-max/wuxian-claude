# 分層像素風池塘水面（色階制、倒影、漣漪、閃光）

- 日期：2026-11-18
- 類型：方法庫
- 標籤：像素美術、2D 水面、倒影、漣漪、line scroll、調色盤、著色器、Godot、Unity、循環動畫
- 主題卷：09
- 來源：使用者提供的 SpriteCook 提示詞；完整教學與測試過的 Python 檔：https://www.spritecook.ai/blog/pixel-art-pond-water-reflections-ripples
- 狀態：未實作驗證。數值是原作者在 320×180 遊戲、約 136×60 像素池塘、3/4 俯視角下測的。2026-11-18 查過本機專案，沒有池塘可套用。

## 一句話摘要

把池塘從「重複平鋪的水圖塊」改成六層合一的水面：每個像素只存調色盤索引（色階），各層互相覆寫，最後才轉成顏色，所以永遠不會混出髒色。

## 核心原則

1. **只用色階，不混色**：每個水面像素存 0–9 的索引，最後一次查表轉顏色。用 alpha 混色會產生幾百種色調，水面變混濁。
2. **深度＋天光決定底色**：離岸越遠越暗；靠鏡頭的那半映天光，越靠近鏡頭越亮。
3. **倒影**：取池塘後方的樹和灌木「這一幀畫出來的樣子」，以底列為軸翻轉、垂直壓到 55%，只留 3 個暗色階，逐列整數像素左右位移（line scroll）。兩個倒影重疊時取較暗的。
4. **細節疊在最上面**：拍岸、對岸晃動、漣漪、閃光、落葉、睡蓮葉，全部共用同一個 5 秒循環。

## 參數表

**調色盤（暗 → 亮）**
- 水：0 `#1d3a44`、1 `#24505a`、2 `#2e6468`、3 `#3f8484`、4 `#5d9fa6`、5 `#6fb3a8`、6 `#c4ece2`
- 7 淺水 `#5a9384`、8 岸邊泥土 `#2c3b36`、9 岸邊草地 `#2d5246`
- 亮度 = 0.3R + 0.59G + 0.11B（0–255）

**深度與天光**
- 填滿的池塘遮罩做 sigma 2 模糊 → 門檻 0.5 → 算到岸邊的歐幾里得距離（貼岸的水 = 1）。
- 距離 < 3 → 色階 3；> 7 → 色階 1；其餘 → 色階 2。
- 天光（距離 ≥ 3 處）：對岸下方第 14 列起色階 3，第 28 列起色階 4。這兩個數約為池塘前後高度的 1/4 和 1/2，要隨池塘大小縮放；其他尺寸一律固定像素數。

**倒影**
- 壓扁 55%。80 像素高的樹 → 44 列倒影。
- 樹的像素亮度低於 dark_cut（所有樹與灌木像素中最暗 15% 的上限）→ 色階 0；低於 110 → 色階 1；其餘 → 色階 2。
- 位移振幅：前 3 列 0，30 列內 1，之後 2；dx = round(amp × sin(y×0.75 − phase(t,2)))。

**岸邊**
- 淺水：貼岸、在池塘中線以下、離實體物 2 像素外的水 → 色階 7。
- 拍岸：沿岸第 2 或 3 圈（隨時間切換），配合沿岸角度的雙正弦波斷續亮成色階 5。不要整圈都亮，否則像描邊。
- 物件接觸處（石頭、蘆葦下緣）：正弦閃色階 5。
- 濕潤地面：池塘旁、中線以上 6 列以下的乾地，亮度 × 0.82。
- 對岸：最上面一列色階 0；往下第 1、2、3、4、6 列鏡射對岸地面（暗 → 0，偏綠 → 9，否則 8），第 4 列以後才左右晃；第 2–5 列加細微波紋。對岸上的亮像素看起來會像霓虹燈，要避免。

**生物與動態**
- 漣漪：5 幀 × 0.2 秒，橢圓半徑 (1,0)(2,1)(4,2)(6,3)(8,4)，只畫邊緣；第 4、5 幀只留 |dy| ≥ ry/2；前 3 幀色階 6，之後色階 5。
- 閃光：20 個，天光區隨機位置與時間，每個 0.6 秒的水平短線，寬度依壽命 1→3→5→4（中空）→2（只剩兩端）；中間色階 6、兩端色階 5；同時約 2.4 個亮著。每個循環重新選位置，否則像壞點。
- 落葉：每循環 2 片；飄落 1.2 秒 → 漂浮 3 秒（每秒 3 像素，下方 1 像素影子，後方拖一個色階 5 像素）→ 下沉 0.6 秒。觸水時產生漣漪；另外每循環 1 滴水滴。
- 睡蓮葉：第 k 片在 sin(phase(t,1) + 1.7k) > 0.4 時下沉 1 像素，下方一列色階 0 影子。

**循環**
- 5 秒；phase(t, cycles) = 2π × cycles × t / 5，cycles 只能是整數，否則接回開頭時畫面會跳。所有位移都四捨五入成整數像素。

## 各引擎做法

- Godot：色階運算寫在 `canvas_item` 著色器，深度和「對岸下方第幾列」預先烘成貼圖；倒影畫進用水面遮罩裁切的 SubViewport。
- Unity：URP 2D 材質 + RenderTexture，作法相同。
- 自製或網頁 Canvas：直接在 CPU 以遊戲原生解析度算，再放大顯示（可參考 2026-11-17 灰燼燈籠的 Uint32 ImageData 寫法）。
- 著色器裡無法比較兩個倒影時，把較暗的色階最後畫。

## 驗證清單

1. 畫落葉和睡蓮葉之前，統計水面顏色數，全部都在調色盤裡。
2. 時間 t 和 t + 5 的畫面完全相同（要傳原始 t 測，不要傳 t % 5）。
3. 80 像素高的樹倒影 44 列，最上 3 列不動，任何一列位移不超過 2 像素。
4. 所有圖層關掉時，整個池塘是單一色階 2。
5. 水滴漣漪 1 秒內 5 幀後消失；落葉漂 3 秒後下沉。

## 素材需求

- 畫進地面的池塘：岸、蘆葦、石頭；睡蓮葉在水面遮罩上挖空。
- 池塘周圍的樹木。
- 先用專案自己的美術；要自創調色盤前先問使用者。
