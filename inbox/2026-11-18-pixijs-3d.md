## 一句話摘要

PixiJS 官方的 3D 擴充：把一個 `View3D` 像 Sprite 一樣加到 2D 舞台上，2D 介面和 3D 場景放在同一個 PixiJS 應用裡。

## 核心內容

- 渲染：WebGL2 和 WebGPU 兩種。
- 模型：glTF，支援 Draco 和 meshopt 壓縮。
- 材質：PBR、Phong、Toon（卡通）。
- 燈光與陰影；骨骼動畫和形變動畫（morph target）。
- 粒子；後處理（Bloom、環境光遮蔽 AO）。
- 3D 物件可以接收滑鼠／觸控事件。
- 需求：pixi.js 8.23.0 以上。有 CDN 版本。
- TypeScript 5 不用設定；TS 6／7 要改用 `@types/web` 取代 `"dom"`，並移除 `@webgpu/types`。extras 要用 `moduleResolution: "bundler"`。

## 可重複使用的規則或模板

安裝：

```
npm install pixi.js @pixi/3d
```

最小場景（節錄自官方 README 的結構）：
1. `new Application()` → `init({ preference: 'webgpu' })`。
2. `new View3D({ autoResize: true, environment: {...} })` → `app.stage.addChild(view3d)`。
3. `Mesh3D` + `Material3D` + `DirectionalLight` 加到 `view3d.root`。
4. `@pixi/3d/extras` 的 `OrbitCamera` 可拖曳環繞。

什麼時候選它，而不是 Three.js：
- 遊戲主體是 2D（UI、卡牌、像素、HUD），只想放一小塊 3D（角色展示、骰子、地球、Boss 模型）。
- 已經在用 PixiJS 或 Phaser 風格的 2D 管線，不想同時維護兩個渲染器。

什麼時候還是用 Three.js：
- 全 3D 遊戲、需要大量現成範例和生態。本機已有一整套 three.js skill（web-engines、build-*、optimize-threejs-games）。
- 專案要穩定：@pixi/3d 才兩個月大。
