## Summary

User wants the `crypto-market-tracker` workflow to catch explosive Bybit USDT perpetual candidates earlier than the existing high-liquidity main scan. The main scan remains useful for confirmed strength, while the new early breakout watchlist is intended to surface lower-turnover symbols before they fully qualify.

## Key Decisions

- Keep the main leaderboard focused on confirmed market strength.
- Add an `Early Breakout Watch` section to `D:\codex\projects\crypto-market-tracker\bybit_market_scan.py`.
- Use the watchlist as an alert/monitoring layer, not as a direct buy signal.
- Treat watchlist candidates as higher-noise and higher-false-breakout than main leaderboard candidates.
- Continue excluding `symbolType=stock` from Bybit linear instruments.

## Main Scan Logic

- Universe: Bybit public V5 `category=linear`, USDT quote, actively trading perpetuals.
- Main liquidity threshold used in the discussion: `24h turnover >= 10M USDT`.
- Momentum confirmation: ticker `24h` change plus rolling `12h / 4h / 1h` changes from 1h klines.
- Candidate must have `24h / 12h / 4h / 1h` all positive for multi-timeframe bullish scan.
- Ranking considers combined momentum, turnover, and a funding heat penalty.

## Early Breakout Watch Logic

- Default watch floor added: `--breakout-watch-min-turnover 3000000`.
- Watchlist candidates are below the main `--min-turnover` threshold but above the watch floor.
- Requires positive `12h / 4h / 1h` momentum from 1h klines.
- Requires recent 4h turnover acceleration or a high recent-turnover share.
- Requires current price to stay close to the recent 12h high.
- Output can be disabled with `--disable-breakout-watch`.

## MAGMAUSDT Lesson

- Around 2026-06-03 12:00 +08:00, `MAGMAUSDT` did not qualify for the main scan:
  - 24h change was slightly negative.
  - 24h turnover was under 1M USDT.
  - 4h and 1h momentum were not both positive.
- By 2026-06-03 20:00 +08:00, it had strong price movement but 24h turnover was still around 6.12M, so it was still blocked by a 10M main threshold.
- Around 2026-06-03 23:00 +08:00, it first met the discussed main-style conditions: strong 24h gain, 24h turnover above 10M, and positive 12h/4h/1h momentum.
- Lesson: strict high-turnover scans catch confirmed strength, but can miss the earlier ignition stage.

## Practical Interpretation

- Main leaderboard: better for confirmed continuation, usually cleaner but often later and more extended.
- Early breakout watchlist: better for earlier discovery, but should require position discipline because false breakouts are more common.
- Watchlist candidates should be checked for:
  - reclaim or hold near recent 12h high
  - fresh 1h confirmation
  - continued 4h turnover acceleration
  - funding not becoming too crowded
  - no immediate rejection after breakout

## Three-Coin Comparison From Chat

- `EPICUSDT`: best chase quality at the time of comparison; clean positive 24h/12h/4h/1h structure and low funding.
- `MAGMAUSDT`: strongest momentum and most explosive, but already extended and funding warmer.
- `LABUSDT`: very liquid but structurally messier; large negative funding suggests event or squeeze risk rather than clean continuation.

## Reuse Notes

- When the user asks why a mooning symbol was missed, check whether it was blocked by turnover threshold, 24h direction, or shorter rolling windows.
- When the user asks for "能不能更早抓", run or improve the early breakout watchlist rather than only lowering the main threshold.
- For reporting, clearly distinguish "can rise" from "confirmed enough to chase".
- Avoid presenting TP levels or watchlist inclusion as promises; use them as conditional targets and monitoring zones.

## Summary

The user wants a recurring Bybit USDT perpetual scan that finds coins likely to continue upward across 24h / 12h / 4h / 1h timeframes. Reports should include candidate rankings, short risk commentary, and explicit TP1 / TP2 / TP3 take-profit levels for each main candidate.

## Durable Decisions

- Use `D:\codex\memory-palace` as `無限` memory for this workflow.
- Use `D:\codex\projects\crypto-market-tracker\bybit_market_scan.py` as the base public-data Bybit scanner.
- Scan public market data only. No account API keys, no orders, no trade execution.
- Universe: Bybit V5 `category=linear`, `quoteCoin=USDT`, `status=Trading`.
- Exclude `symbolType=stock`.
- Liquidity filter: `turnover24h >= 10,000,000 USDT`.
- Direction filter:
  - ticker `price24hPcnt > 0`
  - rolling `12h / 4h / 1h` changes from 1h klines all > 0
- Prefer rolling 12h/4h/1h from 1h candles instead of Bybit's current 12h/4h candle when candle boundary alignment makes values misleading.

## Ranking Method

Rank candidates by:

- 24h / 12h / 4h / 1h percent change consistency.
- Turnover/liquidity bonus.
- Funding heat penalty, especially when positive funding is crowded.
- Extra caution when price is already close to the 24h high.
- Prefer names with enough room to TP1/TP2 over names that are already pinned at resistance.

## Report Format

Each automated report should use Traditional Chinese and include:

- Scan time.
- Method summary.
- Top 5-10 candidates table.
- Columns: symbol, last price, 24h, 12h, 4h, 1h, 24h turnover, TP1, TP2, TP3.
- "Most worth watching" 2-3 names.
- Risk notes: do not guarantee upside; mark crowded/overheated names.

## TP Framing

For each main candidate, include three staged take-profit levels:

- TP1: conservative, near the closest overhead level or small 1h volatility extension.
- TP2: recent major high, 12h/24h high, or moderate 4h volatility extension.
- TP3: breakout-only extension beyond recent highs.

References for TP:

- Current `lastPrice`.
- Recent 4h high.
- Rolling 12h high.
- Bybit ticker `highPrice24h`.
- Rolling 1h/4h volatility.
- Tick size from `instruments-info.priceFilter.tickSize`; use Decimal-based rounding so low-priced coins do not round to zero.

If TP1 is too close to current price or price is near the 24h high, explicitly mark:

- "TP1 很近，等回踩/突破確認"
- "貼近 24h 高點，不宜追高"

## Moving Average Preference

For triple moving averages:

- Main direction on 1h/4h: `9 / 21 / 55 EMA`.
- Shorter entry view: `7 / 14 / 28` or `8 / 21 / 34`.
- Aggressive momentum: `5 / 13 / 34`, only for strong trend/breakout conditions.

Interpretation:

- `9 > 21 > 55` and all rising: trend is still bullish.
- Pullback to 9EMA/21EMA then bounce: healthy pullback.
- Break below 21EMA with 9EMA curling down: short-term caution.
- Break below 55EMA: short-term bullish structure damaged.

## Pullback Checklist

To judge whether a coin may pull back:

- It is near a known pressure level: 24h high, previous high, round number, or recent breakout target.
- 15m/1h structure weakens: lower highs, consecutive lower closes, or break below the previous impulse candle low.
- Volume pattern weakens: rising on lower volume and falling on higher volume is dangerous; falling on lower volume is healthier.
- Key supports are tested: a wick and reclaim is healthier than a clean close below support.
- Moving averages lose alignment or price fails to reclaim the short EMA.

For trade commentary, distinguish:

- Healthy pullback: support holds, selling volume fades, price reclaims short-term level.
- Weak break: support fails, 15m closes below the level, next support becomes likely.
